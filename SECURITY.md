# Security Policy

## Supported Versions

Only the latest public release of **Dao Suprême** is supported with security updates.

Older versions may not receive fixes or patches.

---

## Reporting a Vulnerability

If you discover a security vulnerability in **Dao Suprême**, please **do not create a public GitHub Issue**.

Instead, contact the repository owner privately with the following information:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Proof of concept (if applicable)
- Suggested mitigation (optional)

Responsible disclosure is appreciated and helps protect all users.

---

## Response Policy

Security reports will be reviewed as quickly as possible.

When appropriate, fixes will be developed and released before any public disclosure.

---

## Scope

This policy applies to:

- Dao Suprême Discord Bot
- Official Website
- Documentation
- API (if applicable)
- Assets distributed with the project

---

## Contact

For security-related reports, please contact the repository owner directly.

Thank you for helping keep Dao Suprême secure.
