# Code of Conduct

## Our Commitment

The Dao Suprême project aims to provide a respectful, constructive and professional environment for everyone interacting with this repository.

All participants are expected to behave respectfully and professionally.

---

## Expected Behavior

Please:

- Be respectful toward other users.
- Provide constructive feedback.
- Report bugs responsibly.
- Keep discussions relevant to the project.
- Respect intellectual property and copyright.

---

## Unacceptable Behavior

The following behaviors are not tolerated:

- Harassment or discrimination.
- Personal attacks or insults.
- Spam or advertising.
- Publishing malicious code.
- Sharing illegal or copyrighted material without permission.
- Attempting to bypass the repository rules.
- Unauthorized redistribution of proprietary assets.

---

## Issues and Discussions

When opening an Issue or participating in discussions:

- Stay on topic.
- Provide useful technical information.
- Avoid duplicate reports whenever possible.
- Remain polite even when disagreeing.

---

## Enforcement

The repository owner reserves the right to:

- Remove inappropriate comments.
- Lock discussions.
- Close Issues or Pull Requests.
- Restrict or block users violating these guidelines.

---

## Contact

If you have questions regarding this Code of Conduct, please contact the repository owner.
