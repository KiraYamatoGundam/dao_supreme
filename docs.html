Installation

  1. Utilise le lien d'invitation officiel.
  2. Sélectionne ton serveur.
  3. Vérifie les permissions demandées.
  4. Lance la commande de configuration prévue.

Permissions

N'accorde que les permissions nécessaires. Pour la modération, place le rôle du Bot au-dessus des rôles qu'il doit gérer.

Commandes principales

/config — ouvrir la configuration du serveur.

/setup_secte — installer la structure principale de la secte.

/warn et /warns — gérer les avertissements.

/mute, /kick et /ban — outils de modération.

/niveau et /classement — progression et expérience.

/panels et /reclamer — gestion des tickets.

/poster_verification — publier le panneau de vérification.

/help — consulter l’aide complète disponible sur Discord.

Support

En cas de problème, joins une capture et une description précise sur le serveur support officiel.
