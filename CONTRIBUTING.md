# Contributing

Thank you for your interest in **Dao Suprême**.

At this time, this project is **not open source** and external code contributions are **not accepted** by default.

---

## Bug Reports

If you encounter a bug, please open a GitHub Issue and include:

- A clear description of the problem.
- Steps to reproduce the issue.
- Expected behavior.
- Actual behavior.
- Screenshots or logs (if available).

---

## Feature Requests

Feature suggestions are welcome.

Please create a GitHub Issue and describe:

- Your idea.
- The problem it solves.
- Why it would benefit the project.

Please note that submitting a suggestion does **not** guarantee its implementation.

---

## Pull Requests

Pull Requests are currently **closed**.

The repository owner may occasionally invite trusted contributors to collaborate on specific parts of the project.

Any unauthorized Pull Request may be closed without review.

---

## Intellectual Property

By submitting any contribution, suggestion or other material, you acknowledge that:

- The repository owner retains full control over the project.
- No ownership or licensing rights are transferred.
- Contributions may be modified, accepted or rejected at the sole discretion of the repository owner.

---

## Contact

For collaboration requests or commercial inquiries, please contact the repository owner directly.
